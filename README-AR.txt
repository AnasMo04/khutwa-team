خطوات تشغيل موقع KHUTWA TEAM (مجاني بالكامل)
==============================================

الملفات
- index.html + style.css + app.js + مجلد img : الموقع نفسه.
- config.js : هنا تلصق رابط ومفتاح قاعدة البيانات (الخطوة 4).
- supabase-setup.sql : يبني قاعدة البيانات والأمان بضغطة واحدة (الخطوة 3).

الخطوة 1: إنشاء قاعدة البيانات (Supabase)
1. ادخل supabase.com وسجّل حساب (بالإيميل أو Google أو GitHub).
2. New project: الاسم khutwa، اكتب كلمة مرور قوية واحفظها، واختر أقرب منطقة (أوروبا). انتظر دقيقتين.

الخطوة 2: حساب المنظّم
1. من القائمة: Authentication ثم Users ثم Add user ثم Create new user.
2. اكتب إيميلك وكلمة مرور، وفعّل Auto Confirm User. هذا حساب دخول الداشبورد.
3. (مهم) Authentication ثم Sign In / Providers ثم Email: أوقف "Allow new users to sign up" حتى ما أحد يسجّل حساب بنفسه.

الخطوة 3: بناء الجداول
1. افتح ملف supabase-setup.sql بأي محرر نصوص، وغيّر PUT-YOUR-EMAIL@example.com إلى إيميل المنظّم (نفس إيميل الخطوة 2).
2. في Supabase: SQL Editor ثم New query، الصق كل محتوى الملف واضغط Run.
3. لازم تظهر رسالة Success. إذا ظهر خطأ أرسله لي كما هو.

الخطوة 4: ربط الموقع بقاعدة البيانات
1. في Supabase: Project Settings ثم API (أو API Keys).
2. انسخ Project URL ومفتاح anon (الأفضل المفتاح اللي يبدأ بـ eyJ من تبويب Legacy، أو publishable key).
3. افتح config.js والصق القيمتين بين علامتي التنصيص. هذان المفتاحان عامّان بطبيعتهما، والحماية من قواعد الأمان في ملف SQL.

الخطوة 5: نشر الموقع على Cloudflare Pages
1. سجّل في cloudflare.com (مجاني).
2. Workers & Pages ثم Create ثم Pages ثم Upload assets (رفع مباشر).
3. اسم المشروع هو رابط موقعك: اسمه.pages.dev . اختره بعناية لأن ملصق QR المطبوع مرتبط به. مثال: khutwa-team
4. اسحب محتويات هذا المجلد (index.html وبقية الملفات ومجلد img) واضغط Deploy.

الخطوة 6: أول دخول
1. افتح رابطك واضف في آخره #admin ثم سجّل دخول بإيميل المنظّم.
2. في صفحة "نظرة عامة" اضغط "تهيئة" مرة واحدة (تنشئ الإعدادات وصور الفريق ومنتج التيشيرت).
3. أضف فعالياتك الحقيقية، حدّد السعر والمقاسات، وارفع صورك، وحط رقم واتساب في الإعدادات.

الخطوة 7: ملصق QR وتسجيل الحضور
1. افتح الداشبورد من رابط الموقع النهائي (مهم)، ثم تبويب "الحضور".
2. اختر الجرية واضغط "فتح التسجيل". بدون هذا الزر ما أحد يقدر يسجّل.
3. اضغط "طباعة ملصق QR" واطبعه. الكود يفتح صفحة الحضور مباشرة.
4. جرّب بنفسك وبهاتف ثاني قبل أول جرية رسمية.
5. بعد الجرية اضغط "إغلاق التسجيل". تقدر تصدّر الحضور CSV يفتح في Excel.

ملاحظات مهمة
- الحضور والتسجيلات والحجوزات تظهر فقط للمنظّمين. الزائر يقدر يضيف فقط، ولا يقرأ بيانات أحد.
- عمر المشارك من 1 إلى 99. البيانات شخصية وبعضها لقاصرين: استعمل البيانات لحصر الحضور فقط، ولا تنشرها، واحذفها إذا طلب صاحبها.
- مشاريع Supabase المجانية توقف بعد أسبوع بدون أي نشاط. زيارة الموقع تحسب نشاطًا، وإذا تتوقع أسابيع بدون زيارات اعمل مهمة مجانية في cron-job.org تفتح كل يوم:
  رابط_مشروعك/rest/v1/content?select=id&limit=1&apikey=مفتاحك
- الحد المجاني: 500 ميجا قاعدة بيانات و1 جيجا صور. الصور تُصغَّر تلقائيًا عند الرفع.
- لو تبدّل رابط الموقع بعد طباعة QR، لازم تطبع ملصق جديد.
